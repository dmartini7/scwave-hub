ImPACT Test
Baseline concussion test — required for all players
🧠
ImPACT Baseline Test
Valid for 2 seasons · Complete before or during Kitman Labs workflow
The ImPACT baseline test is required for all players. If your certificate is still valid (within 2 seasons), you can upload the existing certificate or screenshot. If you need to complete a new test, use the steps and screenshots below — the website has been updated since the video guide above.
⚠️
Important — Baseline Test Requirement
Players must submit a "Baseline" Passport ID. The system will not accept a "Baseline +" or "Post-Injury" test as it does not meet the registration requirement.

Additional information and resources on ImPACT's Post-Injury testing for athletes that have suffered a concussion can be found HERE.

26-27 Updated Website — Step-by-Step Screenshots

    Go to the ImPACT test link provided in your Kitman Labs workflow (or use the link provided by Coach Daniel). On the first screen, enter the Division Code HomegrownDivision26 in the coupon field and click Apply Coupon. Then fill in your personal info and proceed.

    On the next screen you'll see "Almost there — Before you begin." Confirm your Division is set to Homegrown and your Club is set to SC Wave, then click Complete & Continue to Baseline Test.
